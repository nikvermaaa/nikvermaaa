## Featured Projects

<details open>
<summary><b>Latent Diffusion Tumor Synthesis — Addressing Data Scarcity in Medical Imaging</b></summary>
<br/>

Engineered a generative AI pipeline using a Latent Diffusion Model (LDM) to synthesize realistic, tumor-bearing brain MRI slices for augmenting limited clinical imaging datasets. Preprocessed the BraTS 2020 dataset (369 patients) into 24,354 normalized cross-sectional tumor slices, then trained a custom UNet with spatial attention to denoise latents via a DDPM scheduler on top of a pre-trained AutoencoderKL.

| | |
|---|---|
| **Stack** | Python, PyTorch / TensorFlow, LDMs, U-Net, KL-Autoencoder, MS-SSIM |
| **Scale** | 369 patients · 24,354 processed tumor slices · Float16 tensors for VRAM efficiency |
| **Performance** | MSE-optimized over 1,000 diffusion timesteps |
| **Validation** | Benchmarked against a 2,436-slice holdout validation set |
| **Repository** | [latent-diffusion-tumor-synthesis](https://github.com/nikvermaaa/latent-diffusion-tumor-synthesis) |

</details>

<details>
<summary><b>Ghosla — AI-Powered Real Estate Voice Agent</b></summary>
<br/>

Architected a real-time voice intake pipeline combining Pipecat, Deepgram nova-3 multilingual STT, GPT-4.1, and Cartesia TTS, delivered via outbound Twilio calls over a WebSocket media stream. Implemented a split-pipeline retrieval system with concurrent browser-use agents scraping property listing sites in parallel with an Exa-based deep search feeding GPT-4 for structured synthesis.

| | |
|---|---|
| **Stack** | Next.js, FastAPI, Pipecat, Deepgram, GPT-4, Twilio, WebRTC |
| **Scale** | 3 concurrent scraping agents across NoBroker, 99acres, MagicBricks |
| **Performance** | End-to-end property search & locality intelligence generation in under 2 minutes |
| **Architecture** | REST + WebRTC full-stack deployment |
| **Repository** | [ghosla](https://github.com/nikvermaaa/ghosla) |

</details>
